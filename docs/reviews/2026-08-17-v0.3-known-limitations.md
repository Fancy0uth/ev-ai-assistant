# v0.3 已知限制与延后改进

## P2 — Provider 删除确认的完整模态键盘约束

- **位置：** `apps/web/src/app/(dashboard)/settings/providers/page.tsx`
- **发现时间：** 2026-08-17
- **现状：** 删除确认使用可命名、可描述且有焦点移动/恢复的内联 `alertdialog`；但它声明 `aria-modal="true"`，未实现 Tab 焦点陷阱或 Escape 取消，并将初始焦点交给不可逆的“确认删除”。
- **影响：** 普通键盘流程可用，且不影响密钥保护、删除的二次确认或日常 iPhone 使用；但辅助技术的严格 modal 预期未完全满足。
- **处理决定：** 依据本轮“仅实现 P0/P1”边界，不在 V3-03b 扩展为通用模态组件。后续在共享无障碍 Dialog 基础设施中处理：移除不完整的 `aria-modal` 或实现焦点陷阱/Escape，并默认将初始焦点交给取消按钮。

## P2 — Provider Settings E2E 覆盖边界

- **位置：** `apps/web/e2e/provider-settings.spec.ts`
- **发现时间：** 2026-08-17
- **已验证：** 未配置状态下，1440×900、390×844 和 320×800 的三个独立浏览器上下文可访问设置页；两个触摸视口没有横向溢出，API Key 输入框和“测试连接”触摸目标均至少为 44px，且没有浏览器 console warning/error 或 `pageerror`。会话只在测试进程内以 `storageState` 传递，未写入磁盘；测试不会输入、保存或打印真实 DeepSeek Key。
- **缺口：** 目前的 Tab 断言只排除了两个已禁用按钮，尚未证明焦点确实进入下一个可交互控件；桌面端没有独立的横向溢出断言，移动端也未测量“保存密钥”按钮；没有网络拦截断言来防止未来页面错误地自动调用连接测试接口。
- **影响：** 不影响当前的未配置流程、密钥不泄露边界或真实 Owner 手工验收；但不能把这项自动化测试表述为“完整键盘、所有触摸目标和无自动副作用”的全面验收。
- **处理决定：** 依据 V3-03b 只实现 P0/P1 的边界，本轮不扩大测试与通用焦点基础设施。后续设置页通用 E2E 补齐真实后继焦点、所有主操作的 44px 测量、全视口溢出检查和对 `POST /connection-test` 的负向网络断言。
