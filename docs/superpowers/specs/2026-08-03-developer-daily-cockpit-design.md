# 开发者每日状态驾驶舱 Demo 设计

## 目标

构建一个可本地打开的前端 Demo，展示面向有代码工作需求的用户如何在一天开始时理解自己的执行状态，并获得任务、学习与生活上的下一步建议。

## 用户与核心场景

用户是需要处理代码、Issue、PR 或学习任务，同时也要兼顾运动、饮食等生活事项的开发者。用户打开首页的首要问题是“我今天的状态怎么样”，而不是“我的任务列表是什么”。

状态由今日任务和日历负荷、昨日任务完成度、昨日学习完成度共同决定。首页使用状态等级、分数、原因拆解和行动建议同时呈现。

## Demo 范围

- 深色桌面端单页，适配较小屏幕。
- 状态卡：分数、等级、趋势和基于 Demo 数据的解释。
- 今日重点：最多三件核心任务；支持完成、推迟、标记为核心。
- 日历时间轴：展示会议、专注时间与生活事项。
- 进度卡：昨天任务完成度和学习目标完成度。
- AI 建议：依据当前本地任务状态，动态调整建议文案；可一键采纳“收缩计划”。
- 生活平衡卡：运动、补水、饮食提醒。

不包含真实账号登录、OAuth、外部日历/ GitHub 同步、推送通知、持久化和真正的 LLM/Agent 调用。所有信息均为浏览器内 Demo 数据。

## 交互规则

- 完成任务会改变今日完成进度、状态分数和 AI 建议。
- 推迟任务会把任务移至稍后，并降低状态分数。
- 点击“收缩计划”会将一个非核心任务标记为稍后完成，展示 toast 提示。
- 点击“开始专注”会在当前核心任务上呈现专注状态提示。

## 视觉方向

使用石墨深色背景、蓝紫渐变主色、薄荷绿积极状态色及温暖琥珀色提醒色。信息层级为：状态摘要 > 三件核心行动 > 时间安排 > AI/生活支持。避免密集传统看板，采用有留白的半透明卡片。

## 验收条件

1. 直接打开 `index.html` 可看到完整中文首页。
2. 页面能在无网络、无后端情况下运行。
3. 任务完成、推迟、收缩计划和开始专注都有可见反馈。
4. 任意交互后状态分数、完成统计或 AI 提示至少有一项真实更新。
5. 页面在 1280px 和 390px 宽度下不存在横向溢出，主要内容仍可用。
