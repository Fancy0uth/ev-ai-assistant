# v0.7 Fitness and Nutrition Loop 实施计划

**Goal:** 完成身体 check-in→Signal→Workout Proposal→确认→反馈和自然语言餐食→权威营养数据→确认两条真实闭环，不做医疗诊断。

**Binding:** [总设计](../specs/2026-08-23-v0.4-v0.9-mvp-design.md) · [总路线](2026-08-23-v0.4-v0.9-mvp-roadmap.md) · 入口为 v0.6 PASS commit

## 版本边界

- Check-in 是用户自述信号，不是病历；系统只能给训练负荷/恢复建议和明确的安全停止提示，不诊断、不治疗、不替代医生。
- 训练建议来自可审计动作目录和确定性安全规则；RAG 内容是不可信资料，不能改变工具/权限。
- 营养数值必须来自权威、带版本的数据源；模型只解析餐食候选，Core 计算总量，Owner 确认后才入账。
- 所有身体与饮食数据本地、Owner-scoped；外发遵循 v0.5 provider envelope，日志不得保存原文。
