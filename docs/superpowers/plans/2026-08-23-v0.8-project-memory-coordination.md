# v0.8 Project, Memory and Coordination 实施计划

**Goal:** 交付只读本地项目分析、可审查长期记忆和跨模块唯一排程 Proposal；项目链绝不写代码或 Git。

**Binding:** [总设计](../specs/2026-08-23-v0.4-v0.9-mvp-design.md) · [总路线](2026-08-23-v0.4-v0.9-mvp-roadmap.md) · 入口为 v0.7 PASS commit

## 版本边界

- 项目目录只能在本机 CLI 显式授权；Web/BFF 永远不能提交本机路径或访问 local-admin route。
- snapshot 是有界、allowlist、无 symlink traversal 的只读输入；项目 Provider 没有文件写入、shell、Git、补丁或网络工具。
- 所有记忆保存在本地 SQLite/Markdown 投影，Owner 与实体作用域隔离；自动压缩有预算、lineage、diff、确认/回退。
- 多模块只能生成一个 owner/date 的活跃协调 Proposal；确认后才改变排程，不得各自直接写 Event。

## 执行期显式假设与审批门

- 若选择本地 Codex/其他 CLI 作为真实 analyzer，执行时必须先冻结其只读命令、工作目录、网络/工具能力和审计方法，并由主 Agent单独审批；无法证明零写入则保持不可用。
- 本机项目 scope 授权是 Owner 本地动作；不得从 iPhone/Web 触发。任何新模型调用、外部网络、push 或发布需单独审批。
