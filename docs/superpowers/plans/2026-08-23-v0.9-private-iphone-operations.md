# v0.9 Private iPhone Operations and Final MVP 实施计划

**Goal:** 通过认证私有 HTTPS Web 边界让物理 iPhone Safari 可用，同时补齐 Windows 常驻、自启动、SQLite WAL 安全备份恢复、脱敏日志/health，并执行最终完整 MVP 门禁。

**Binding:** [总设计](../specs/2026-08-23-v0.4-v0.9-mvp-design.md) · [总路线](2026-08-23-v0.4-v0.9-mvp-roadmap.md) · 入口为 v0.8 PASS commit

## 版本边界

- Core 始终只监听 `127.0.0.1`；私有网关/隧道只代理 Web，禁止裸露公网 Core、0.0.0.0 Core、端口转发直达 Core。
- 远程写入仍受 Owner session、Origin/CSRF、Proposal+Confirm；私有网络身份不能替代应用认证。
- 所有数据/记忆/日志/备份本地，Key 由 DPAPI 保护；备份不包含可解密明文 Key。
- Tailscale 安装/登录/Serve、端口/防火墙、系统任务/服务、真实恢复、物理设备访问、push/发布都需主 Agent 在执行时分别审批；本计划不授权现在执行。
- v0.9 是实现版本，不是对外稳定 1.0、公开发布或兼容性承诺。

## Tasks

### V9-01 — 固化 Web-only 私有 HTTPS、认证与 CSRF 边界

**依赖：** v0.8 PASS。

**文件：** `apps/core/src/server.ts`、`apps/core/src/modules/health/routes.ts`、`apps/web/src/app/api/core/[...path]/route.ts`、`apps/web/src/lib/core-client.ts`、`apps/web/tests/core-proxy-security.test.ts`。

**网络契约：** Core 启动拒绝非 loopback host；BFF 只连接固定 loopback Core，不接受用户目标 URL；mutation 要求认证 session、可信 `Origin` 与 CSRF header/cookie 绑定；设置 HSTS/CSP/frame/referrer/nosniff，cookie Secure/HttpOnly/SameSite。私有网关只把已认证 HTTPS 流量送到 loopback Web。

**允许/禁止：** 只写 bind guard、BFF/client/security test；禁止 wildcard Origin、Host 信任、匿名 mutation、BFF 代理 local-admin/project scope、Core 公网监听。

- **RED:** 测试 `0.0.0.0`/LAN Core bind 拒绝、伪造 Host/Origin、缺 CSRF、跨站 cookie、local-admin proxy deny 和 HTTPS security headers；运行 `npm test --workspace @ev/core -- tests/health.test.ts` 与 `npm test --workspace @ev/web -- tests/core-proxy-security.test.ts`，预期失败。
- **GREEN:** 实现 loopback invariant、固定 upstream 和 Origin/CSRF/header policy；同一命令通过。
- **重构/提交:** Core/Web typecheck、聚焦 lint；提交 `feat(security): enforce private web-only remote boundary`。

**验收：** 扫描与启动证据证明 Core 只在 loopback；iPhone 可达的唯一入口是认证私有 HTTPS Web。

## 执行期显式假设与审批门

- 私有 HTTPS 首选 ADR 指定的 Tailscale Serve；实际安装、登录、Serve、证书、端口/防火墙变更必须逐项由主 Agent 审批。若不能证明 private+authenticated+HTTPS，物理远程验收阻塞，不能暴露 Core 代替。
- Task Scheduler/服务真实注册与删除、主机重启验收、真实数据备份恢复均需对精确命令/目标另行审批。
- 物理 iPhone、任何外部共享、push、tag、发布或部署均需新授权；v0.9 PASS 本身不授权这些动作。
