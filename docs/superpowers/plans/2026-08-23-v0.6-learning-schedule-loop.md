# EV AI Dashboard v0.6 Learning and Schedule Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to execute this plan in order. One `gpt-5.6-terra` worker with `xhigh` reasoning and priority owns all four tasks continuously; it must not dispatch subagents or pause between tasks for user confirmation.

**Goal:** Deliver one reviewable loop from a private timetable image through Course/recurrence creation and an accepted SCHEDULE Proposal into Today, then from safe public citations through a confirmed Learning Action + TimeRequest into the existing daily planner.

**Architecture:** Keep the same-origin Next.js BFF, loopback Fastify Core and SQLite authority. Replace Base64 JSON with a bounded raw-image boundary, keep every external response in strict untrusted-data contracts, and split external disclosure, domain confirmation and schedule confirmation into explicit versioned stages; Vision and public search remain provider-neutral capabilities that are absent in production until separately approved adapters are configured.

**Tech Stack:** Node 24 built-ins (`node:fs`, `node:crypto`, `node:dns`, `node:https`), TypeScript 6, Next.js 16, React 19, Fastify 5, better-sqlite3 13, Zod 4, Vitest 4 and Playwright 1.62. No dependency installation is part of v0.6.

**Spec:** `docs/superpowers/specs/2026-08-23-v0.4-v0.9-mvp-design.md`; product authority remains `docs/product/PRD.md` and `docs/product/MVP-SCOPE.md`.

**BASE:** `155b172de91a62feb2762469536555f9a6b2b025` (`155b172`), the closed v0.5 engineering PASS baseline on `codex/product-prd`.

## Global Constraints

- Single local Owner. Every artifact, import, revision, Course, source, capability run, Action, TimeRequest, Proposal and audit query starts with `owner_id`; cross-Owner lookup and deletion return `404`, not an existence oracle.
- Core remains bound to `127.0.0.1`; browsers call only `/api/core/*`; SQLite, artifact paths and Core port `4311` never become browser-visible endpoints.
- Images, Vision/OCR output, search results, public pages and model output are untrusted data. They cannot select tools, SQL, paths, hosts, redirects, prompt roles or side effects.
- External disclosure is persisted and shown before each external request. A request without an available capability remains `BLOCKED_PROVIDER`; there is no sample-success production fallback.
- Fake adapters require all three gates: `NODE_ENV=test`, `EV_E2E_V06_LEARNING_TEST_ADAPTERS=1`, and a database/artifact root resolving inside runner-owned `EV_E2E_RUN_DIR`. App composition rejects a Fake descriptor if any gate fails.
- DeepSeek is eligible only for the text-only `LearningAdviceCapability`; it is never registered as `VisionCapability` or `PublicSearchCapability`.
- High confidence changes display priority only. Every Vision result enters an immutable candidate revision and must be reviewed by the Owner.
- Course/Rule creation, Learning Action/TimeRequest creation and Event expansion use Proposal/Confirm, optimistic version, semantic idempotency and immutable audit records.
- No network, DNS, Provider, DPAPI, file read or file delete is performed inside a SQLite immediate/write transaction.
- Migration v19 is additive only. It does not drop, rename, rebuild or rewrite an existing table/column and never updates historical `app_version` values.
- No real paid call, credential, network test, dependency install, school login/Cookie/CAPTCHA, Apple calendar, wearable, native app, deployment, push or release is authorized by this plan.
- The v0.5 `P2-EVIDENCE-001` hybrid E2E debt remains unchanged. v0.6 adds separately labelled Fake evidence and does not refactor the v0.5 Daily Plan fixture boundary.

### 1.4 Raw upload decision and dependency gate

Use Fastify 5 `addContentTypeParser()` for exactly `image/png`, `image/jpeg` and `image/webp`, with `parseAs: 'buffer'` and route `bodyLimit: 5_000_000`. This is a bounded raw-body solution using installed/runtime capabilities; multipart is unnecessary.

If Terra finds a proven Fastify incompatibility that cannot be solved with the installed API, it must keep the raw endpoint as the no-install alternative and escalate to Sol. Adding `@fastify/multipart`, changing a package manifest or running an installer requires a separate user approval and is not an internal repair round.

### 1.5 Capability execution policy

`CAPABILITY_POLICY_V1` is local and deterministic. Vision permits one Provider call/run, 5,000,000 image bytes, 100,000 output characters and a 30-second total deadline. Public search permits one Provider call plus at most five pinned HTTPS fetches/run, query length 300, 20,000 Provider output characters, 1,048,576 bytes/fetch and a 15-second deadline per call. Learning advice permits one Provider call/run, 20,000 total input characters, 8,000 output characters and a 15-second total deadline. Each capability has an Owner/local-date ceiling of 20 Provider calls; the claim transaction reserves the call before network and a terminal transaction records actual counts/outcome.

An expired `RUNNING` lease is terminalized to `FAILED/CAPABILITY_EXECUTION_STALE` at startup without invoking a Provider. Same Owner/idempotency key/request hash reconstructs the stable domain run response and sets replay evidence; same key with another hash returns `409 IDEMPOTENCY_KEY_REUSED`.

```ts
interface PublicResourceFetcher {
  fetch(input: { url: string; expectedContentHash?: string }): Promise<{
    canonicalUrl: string;
    publisher: string;

    retrievedAt: string;

```

Search result schema permits 1–5 items with bounded title, publisher hint and HTTPS URL and rejects unknown fields; persisted `publisher` is derived from the final canonical URL’s ASCII hostname, not trusted from the hint. URL policy permits `https:`, empty username/password, empty/default port only, and rejects localhost/`.local` plus loopback, private, link-local, carrier-grade NAT, documentation, benchmark, multicast, reserved, unspecified, IPv4-mapped-private and IPv6 ULA/link-local ranges. `dns.lookup({all:true,verbatim:true})` must return only public addresses. `node:https.request` receives a lookup callback pinned to those addresses. Redirects are manual, maximum 3, and every hop reruns URL/DNS policy. Requests send `Accept: text/html,text/plain`, `Accept-Encoding: identity`, no Cookie, Authorization or browser headers; reject encoded bodies, content length/stream over 1,048,576 bytes, non-HTML/text, non-UTF-8, headers after 5 seconds or total after 15 seconds.

HTML/text remains untrusted, is normalized to at most 24,000 characters for an in-memory data channel, never rendered with `dangerouslySetInnerHTML`, and is discarded after hashing. Page instructions such as “ignore previous rules” are preserved only as quoted data and cannot alter capability/tool/schema selection.
