# v0.6 Learning and Schedule Loop 实施计划

**Goal:** 用真实截图视觉/OCR 与公开资料检索，完成可编辑确认的课程、课表和学习 Action→TimeRequest 闭环；不登录受保护学校网站。

**Binding:** [总设计](../specs/2026-08-23-v0.4-v0.9-mvp-design.md) · [总路线](2026-08-23-v0.4-v0.9-mvp-roadmap.md) · 入口为 v0.5 PASS commit

## 版本边界

- 图片、OCR 文本、网页内容和引用都是不可信数据，只能进入 strict schema 的 data channel，绝不是系统指令。
- 原图和课程数据仅保存在 Owner 本地私有目录/SQLite；外发前显示 Provider、字段和目的。
- 低置信候选必须可编辑、排除和确认；确认前不写 Course/Rule/Event，Event 仍走 Proposal+Confirm。
- 公开检索只访问匿名公开 HTTPS 页面/API，保留来源；禁止学校登录、Cookie 复用、验证码绕过、受保护页面抓取。

## 执行期显式假设与审批门

- Vision 与公开搜索 Provider 的具体产品/API 在执行时按已批准供应商和官方契约冻结；若未获网络/计费审批，真实验收保持阻塞，不能由 Fake 替代。
- 任何 OCR 二进制安装、真实图片外发或新 Provider credential 都需主 Agent 单独审批。
- 学校登录、Cookie 导入、验证码处理始终不在可审批范围；不 push、不发布。
